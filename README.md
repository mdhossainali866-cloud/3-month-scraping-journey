# 🚀 Quotes & Tags Web Scraper

A lightweight Python web scraper built to extract quotes, author names, and associated tags from [Quotes to Scrape](https://quotes.toscrape.com/).

This is **Project 1** of my **3-Month Web Scraping & Automation Journey**.

---

## ✨ Features
- Scrapes quote text, author names, and category tags.
- Handled UTF-8 character encoding for clean terminal output across platforms.
- Utilizes Python list comprehensions for efficient tag parsing.

---

## 🛠️ Technologies Used
- **Language:** Python 3
- **Libraries:** 
  - `requests` - For sending HTTP requests
  - `beautifulsoup4` - For HTML parsing
